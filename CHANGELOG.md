# Changelog

## 1.0.0

- Crawler Neon: one colour per Ace jacket, on a very dark grey ground. Purple UI accent, tinted active tabs and status bar,
  bold function definitions, six-colour bracket pairs, full notebook, test explorer, debugger, terminal, diff and merge colours.
- Crawler Deluxe: the light sibling, cream and parchment surfaces with the book hues darkened for daylight.
- Both themes define VS Code's classic and experimental Modern UI tab colours.
- Optional Custom CSS files: `speckle/` for the jackets' grain, `chrome/` for rounded tabs, panes, palette and widgets.
- `shell/`: a matching prompt, as an oh-my-posh theme and as a plain zsh file.
- `terminal/`: an Apple Terminal profile. `vim/`: a Vim and Neovim colour scheme. `eza/`: an eza theme.
